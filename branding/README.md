# IR-SIM brand assets

These files provide consistent IR-SIM branding across GitHub, PyPI, and the
documentation.

- `ir-sim-logo-light.png`: transparent horizontal logo for light backgrounds.
- `ir-sim-logo-dark.png`: transparent horizontal logo for dark backgrounds.
- `ir-sim-mark.png`: square symbol for avatars, favicons, and compact layouts.
- `ir-sim-social-card.png`: 1280 x 640 image for repository and link previews.

Keep the logo proportions unchanged and leave clear space around the mark. Use
the light or dark logo according to the surrounding background; use the social
card when a platform requires a fixed preview image.
