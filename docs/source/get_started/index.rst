Get Started
===============

Start with a working scene, then connect its YAML parameters to the model.

.. list-table:: A short learning path
   :header-rows: 1
   :widths: 28 72

   * - Step
     - What you will learn
   * - :doc:`install`
     - Install the package and check your environment.
   * - :doc:`quick_start`
     - Run one robot and change one scenario parameter at a time.
   * - :doc:`../concepts`
     - Understand states, actions, sensors, and the simulation lifecycle.
   * - :doc:`kinematics`
     - Experiment with coordinate frames and time-step accuracy.
