Copy / Allocation Analysis — NumPy Kernel

The NumPy kernel allocates 4 x (chunk_size x N_beams) float64 matrices per chunk pass inside _nonparallel_hit_distances: denominator, segment_position, ray_distance, and valid_hit (bool). With chunk_size = 1024 and N = 360 beams, one chunk = 4 x 1024 x 360 x 8 B ~ 11.8 MB. A 5 000-segment scene uses ⌈5000/1024⌉ = 5 chunks -> 59 MB of temporaries per scan step, dominated by memory bandwidth.

Numba JIT fix: the JIT kernel loops over beams with prange and segments with a plain for. Working state per thread is 2 scalars (best_t, best_j) — no matrix allocation at any scale. Total live memory = O(N) output + O(1) per thread regardless of M.
